# Privacidade

Este repositório contém **só o código do aplicativo**, igual para todo mundo que abre o endereço.

- Nenhum dado financeiro, senha, backup ou fatura é enviado para o GitHub ou para qualquer servidor.
- Os dados ficam apenas no navegador do celular de cada pessoa, criptografados com a senha dela (AES-256-GCM).
- O GitHub Pages só entrega os arquivos do app. Ele não recebe o que você digita.
- A única conexão possível é com o Google Drive, e só se você mesmo ligar o backup automático. O app só enxerga os arquivos que ele criou lá.
- Nunca coloque backups (`financas-backup-*.json`), faturas ou planilhas neste repositório.
